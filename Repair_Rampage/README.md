# Repair Rampage

## Overview
Repair Rampage is an action-packed game where you race against the clock to fix broken machinery and equipment. Test your skills, speed, and problem-solving abilities in increasingly challenging scenarios.

## Features
- Fast-paced repair mechanics
- Progressively difficult levels
- Engaging gameplay
- Intuitive controls

## Getting Started
1. Clone the repository
2. Install dependencies
3. Run the game (index.html)
4. Start repairing!

## How to Play
- Use your tools to repair damaged items before time runs out
- Complete objectives to progress to the next level
- Earn points for completing repairs quickly and efficiently
