Introductie tot HTML

HTML (HyperText Markup Language) is de standaardtaal voor het maken van webpagina's en webapplicaties. Het vormt de structuur van de inhoud op het web en is de basis van elke website.

HTML bestaat uit een reeks elementen, die worden weergegeven door tags zoals <h1>, <p>, en <a>. Deze elementen kunnen koppen, alinea's, links, afbeeldingen en andere inhoud definiëren.

De structuur van een basishtml-document ziet er als volgt uit:

<!DOCTYPE html>
<html>
  <head>
    <title>Pagina Titel</title>
  </head>
  <body>
    <h1>Dit is een kop</h1>
    <p>Dit is een alinea.</p>
  </body>
</html>

Dit is een zeer eenvoudige structuur die de basis vormt van elk HTML-document. Het <head>-gedeelte bevat metadata zoals de titel, terwijl het <body>-gedeelte de zichtbare inhoud van de pagina bevat.

Wanneer je eenmaal vertrouwd bent met de basisstructuur, gaan we verschillende HTML-tags verkennen om complexere pagina's te maken!

Stap 1: De <h1> Tag

De <h1> tag wordt gebruikt om de hoofdtekst van een pagina te maken. Het wordt meestal gebruikt voor de titel van de pagina of sectie.

Voorbeeld:

<h1>Dit is een kop</h1>

Hoe het eruit ziet:

Dit is een kop

Nu kun je je eigen <h1> tag schrijven.

Stap 3: De <a> Tag

De <a> tag wordt gebruikt om hyperlinks te maken. Je kunt het gebruiken om naar andere pagina's of websites te linken.

Voorbeeld:

<a href="https://www.voorbeeld.com">Bezoek Voorbeeld</a>

Hoe het eruit ziet:
